# Trend Insight Analysis

当任务目标是“解释趋势”，而不是“展示表格”时，使用本 skill。

## 何时触发
- 用户要求分析 AI 趋势变化
- 用户要求解释同比、环比、滚动变化
- 用户要求说明“是更多销售开始提 AI，还是少数销售提得更频繁”
- 用户要求给出趋势后的业务解释和下钻方向

## 不要用于
- 生成页面代码
- 直接修改正式标签
- 处理复核结果写回
- 从原始文档直接做抽取

## 工作流
1. 先读取 `references/input_contract.md`，确认允许使用的数据对象。
2. 优先读取 `dashboard_snapshot` 与 `sales_monthly_rollup`，不要直接从散乱 CSV 拼判断。
3. 对每个趋势判断同时回答三件事：
   - 变化是什么
   - 变化由什么驱动
   - 值不值得业务动作
4. 输出前检查：
   - 不只复述数字
   - 至少给出一个下钻对象
   - 结论能回链到证据或销售对象

## 失败边界
- 如果输入缺少销售个人维度，必须明确指出“无法判断是销售人数增加还是少数销售更活跃”。
- 如果输入只有数量没有证据，不得给出强结论。
- 如果同比口径不完整，必须明确说明可比范围。

## 输出要求
- 只输出 `references/output_contract.md` 定义的字段。
- 用业务语言，不用模型自夸式描述。
- 不得把弱信号包装成趋势结论。
