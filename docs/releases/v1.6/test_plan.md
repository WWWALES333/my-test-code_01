# v1.6 测试方案

## 1. Minimax 接入
- Key 只能从环境变量或 Keychain 读取。
- `.com` 域名可用，`.io` 不作为默认配置。
- `<think>` 输出可被清洗。
- JSON 可被稳健提取。
- 模型失败进入复核，不自动 confirmed。

## 2. 业务问题识别
- 医生接纳度可分类。
- 医生直接诉求和间接机会可区分。
- 销售自用 / 对外介绍 / 学习复盘可区分。
- 竞品动作不污染我方产品 AI 主结论。

## 3. 复核学习闭环
- 每轮最多 20 条 open 任务。
- 已复核结果能生成学习摘要。
- 系统能自动输出规则、Prompt、标签扩展候选。
- 黄金样本可用于后续回归。

## 4. 看板验收
- 首页 3 分钟可读。
- 趋势页显示周/月时间窗口。
- 销售页落到个人。
- 洞察页包含业务意义和行动建议。
- 复核页是卡片式，不暴露工程字段作为主交互。

## 5. 回归保护
- `src/main.py` 行为不变。
- v1.3/v1.4/v1.5 既有测试通过。
- `tests/check_no_secrets.py` 通过。
