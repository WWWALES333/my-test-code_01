# AI 一线情报工作台 MVP 测试方案

**版本**：v1.5  
**状态**：正式基线  
**阶段**：开发前确认版

## 1. 版本说明
本测试方案用于验证 `v1.5` 是否真正从“可跑的 AI 看板”升级为“可判断、可追溯、可复核”的 AI 一线情报工作台。

## 2. 测试目标
- 验证趋势中心能回答同比、环比、渗透率与结构变化问题。
- 验证销售中心能稳定下钻到销售个人。
- 验证结论中心能输出可追溯的业务结论卡。
- 验证复核工作台能完成文件回写闭环。
- 验证首批 2 个 skill 的输出可直接被工作台消费。
- 验证不影响 `v1.2` 主链路。

## 3. 测试范围
- 规范化中间层构建
- 趋势聚合与趋势解释
- 销售个人归一与销售画像
- 结论卡生成
- 复核任务生成与复核结果写回
- Web 工作台展示与下钻
- 仓库内 skill 输出契约

## 4. 数据基线与样本策略
### 4.1 数据范围
- 主分析范围：`2025-01` 至当前 `2026` 归档数据
- 回归范围：`v1.3` 冻结样本
- 问题复盘范围：`v1.4` 复核队列和机会池

### 4.2 样本分层
- 回归样本：验证标签和基础追溯口径不退化
- 趋势验证样本：验证时间序列与销售活跃度口径
- 结论验证样本：验证结论卡质量与证据回链

### 4.3 覆盖要求
- 周报 / 月报均覆盖
- 云诊室 / 云管家 / 混合均覆盖
- 高质量机会样本、医生反馈样本、销售行为样本均覆盖
- 模板文本、资料整理、泛 AI 表达等低价值样本均覆盖

## 5. 趋势中心验证
- 能输出月度趋势并显示 `2025` 对 `2026` 同期对比
- 能回答：
  - AI 提及是否上升
  - 活跃销售人数是否上升
  - 销售渗透率是否上升
  - 哪类主体变化最明显
  - 哪条业务线变化更明显
- 趋势结论不得只复述数字，必须带业务解释和下钻线索

## 6. 销售中心验证
- 每条销售记录都有稳定销售主键
- 不允许模板名、报告标题直接作为销售个人展示
- 每个销售页面至少展示：
  - AI 提及次数
  - 覆盖周数 / 月数
  - 主体分布
  - 业务线分布
  - 医生反馈数
  - 代表证据
- 能识别持续活跃、新近活跃、偶发提及、长期沉默四类状态

## 7. 结论中心验证
- 结论卡必须由证据簇生成，不直接复述单条证据
- 每张结论卡都必须能回到代表证据
- 结论中心必须覆盖：
  - 云诊室结论
  - 云管家结论
  - 销售行为结论
  - 产品机会结论
- 模板文本、资料整理类文本不得作为高质量结论主证据

## 8. 复核工作台验证
- 待复核项能在页面查看
- 每项能显示：
  - 原文
  - 上下文
  - 当前判断
  - 原始文件路径
  - 复核原因
- 修改后能写入 `review_decisions`
- 下一轮运行能消费已复核结果
- 已复核项不得继续以未处理状态原样重复出现

## 9. 证据追溯验证
- 趋势结论 -> 销售 / 证据 -> 原文路径链路完整
- 销售画像 -> 代表证据 -> 原文路径链路完整
- 结论卡 -> 证据 -> 原文路径链路完整
- 证据追溯率要求 `= 100%`

## 10. skill 输出验证
首批 skill 验证对象：
- `trend-insight-analysis`
- `evidence-to-insight`

验证要求：
- skill 输出符合其约定字段
- `trend-insight-analysis` 不能只复述统计表
- `evidence-to-insight` 不能只复述标签和原文
- skill 输出必须能被工作台直接消费
- skill 输出失败时，不得阻塞主链路产物生成

## 11. 回归测试
- `v1.3` 冻结样本的基础标签口径不退化
- `v1.4` 已识别问题在 `v1.5` 中有明确处理路径
- 不影响 `v1.2` 下载、归档、审计、通知主链路
- 安全检查脚本通过

## 12. 人工验收记录方式
首轮人工验收应至少记录以下字段：
- `sample_id`
- `task_id`
- `report_id`
- `segment_id`
- `salesperson_id`
- `expected_result`
- `actual_result`
- `is_pass`
- `review_comment`
- `need_rule_update`
- `need_skill_update`
- `need_annotation_update`
- `reviewer`
- `reviewed_at`

建议验收分三组：
- 趋势验收
- 结论验收
- 复核闭环验收

## 13. 封板标准
- 趋势中心能回答同比、环比、渗透率问题
- 销售中心稳定落到销售个人
- 结论卡全部可追溯
- 已复核结果可进入下一轮消费
- skill 输出可直接服务趋势中心和结论中心
- `v1.2` 主链路无回归
- 安全检查通过
