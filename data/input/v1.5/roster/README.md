# roster 目录说明

本目录用于放置 `v1.5` 运行时依赖的销售花名册本地文件。

## 1. 当前用途
- 生成 `sales_roster.jsonl`
- 作为销售个人主数据基线
- 计算沉默销售、销售渗透率和区域构成
- 把正文中的花名归一到稳定销售对象

## 2. 文件要求
- 当前默认文件格式：`.xlsx`
- 当前字段口径：`花名 / 汤名 / 组织全称 / 部门 / 职务`
- 当前按“在岗快照”解释，不做历史任职追溯

## 3. 提交规则
- `roster/*.xlsx` 已被 `.gitignore` 忽略，不提交到 GitHub
- 本目录只提交说明文件，不提交真实花名册内容
- 若花名册更新，直接替换本地 Excel 后重跑 `v1.5`
